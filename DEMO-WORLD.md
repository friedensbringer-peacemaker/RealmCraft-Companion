# Optional demonstration world — proposal

Status: planned; no demo download or settings integration is provided by this initial source publication.

The demonstration should explain the Companion through a small, easy-to-understand saved world. Distribute it separately from source code only after an explicit review of the final world and its metadata.

## Suggested layout

| Area | Contents | What visitors can try |
| --- | --- | --- |
| Small starter house | Bed, workbench, door and a clear entrance | Find the house on the map; compare the map with the saved world |
| Building-material chest | For example 32 wooden blocks, 16 stone blocks and 8 glass blocks | Search for items and inspect clear quantities |
| Tool chest | A few tools, including one with visible wear | Explore item identification and compare with the player view after equipping a tool |
| Treasure chest | For example 3 diamonds and 5 lapis lazuli | Search distinctive items and compare storage locations |
| Second small storage area | One additional chest a short walk away | Find separate places and inspect distances |
| Marked construction site | Space for a small future build | Compare a backup before and after making a change |

Label chests clearly with signs. Keep the item counts small enough to verify by eye. Final expected results must be recorded from the finished saved world; the example quantities above are a proposed checklist, not a claim about existing data.

## Intended download behavior

- Offer a clearly labeled, optional demo download in settings.
- Show the demo version and download size before downloading.
- Verify the archive against a pinned SHA-256 value and validate safe extraction paths.
- Import through the existing backup-library validation path as a new entry.
- Keep existing worlds intact and do not restore to a Quest automatically.
- Explain that editing the demo locally does not update the published example.

These are implementation requirements for a future change, not currently available functionality.
