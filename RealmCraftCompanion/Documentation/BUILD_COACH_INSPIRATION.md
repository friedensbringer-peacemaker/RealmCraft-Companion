## Implemented interaction

The catalog shows schematic thumbnails generated from its own voxel data, not third-party pictures. The coach has one current step, 2D or 3D preview, material disclosure, read/repeat and stop, and optional speech after an explicit Next action. Finishing speech never advances construction. The app stores the viewed step against the exact English instruction sequence; changing that sequence resets an old checkpoint. Viewing a step is not a placement confirmation or gameplay validation.

Mac system speech uses existing voices and requires no new API account. It does not listen for commands. For eyes-free Quest use, the user transfers the complete agent briefing and optional checkpoint to their chosen voice app. The briefing establishes a fixed building reference, limits spoken actions to at most five identical blocks, waits for explicit confirmation, and covers repeat, simpler, orientation, pause and resume. No headset observation or automatic progress synchronization is claimed.
