# Video knowledge exports

In Videos & tips, open a video to read its short summary. Use **Export video as Markdown** to save that video's authored notes, prerequisites, steps, timestamp links and review limitations in the selected interface language.

Select **Include this video in the overall AI export** to remember it for later. The AI export page also provides a list of reviewed videos and a switch to include selected video knowledge when generating the world document. Regenerate an existing export after changing the selection.

Video notes remain inline until the combined Markdown text exceeds 100,000 UTF-8 bytes. Above this threshold, or when **Always save video knowledge as a second Markdown file** is selected, saving produces a main file and a linked video file. Attach both files to the agent. Local saving, iCloud and AirDrop preserve both files. JSON retains all selected notes in one file.

Exports contain authored summaries and instructions, not full original transcripts or audio. Review status distinguishes reviewed notes from pending metadata and identifies limited visual sampling. YouTube timestamp links lead back to the original source. No video is downloaded or played by exporting.
