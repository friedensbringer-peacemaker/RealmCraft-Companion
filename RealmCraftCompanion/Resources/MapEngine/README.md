# Realmcraft Atlas integration snapshot

Imported from the concurrently developed RealmcraftMap project on 5 September 2026. This copy is intentionally independent so ongoing importer changes cannot alter a released companion. It reads world files and generates offline browser maps with original schematic colors. Dependencies: Python >=3.10, NumPy >=2,<3 and Pillow >=10.4,<13. The companion can create its own virtual environment; it never changes the system Python. The standalone project remains the upstream source.
