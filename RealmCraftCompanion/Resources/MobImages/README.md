# Original RealmCraft VR model previews

24 static previews rendered from the user's existing local Quest APK on 2026-09-06. Original meshes, bone transforms, bind poses and material textures are used. Neutral SceneKit lighting and the prefab rest pose differ from in-game animation and shaders. Wolf uses the original pale-wolf texture. No AI artwork or Minecraft replacement images.

RealmCraft artwork remains the property of its respective rights holders; it is not covered by the Companion source-code license. These local previews do not establish release availability. Baby entries can display an explicitly labelled adult reference; no baby geometry is fabricated. Horse, zombie horse and frog have no verified model preview here.

`provenance.json` records the APK SHA-256 and source mesh/material identifiers. PNGs are excluded from the CommunitySource.zip code export. The application works without these optional images and shows an explicit missing-image state.
